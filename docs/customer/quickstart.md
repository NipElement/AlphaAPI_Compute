# ARISE Compute — 客户快速上手

控制台地址、账号、可用配额和接入配置由平台开通时交付。当前提供开发机、训练任务、在线服务、存储卷和用量查询；具体可用规格以控制台为准。

## 登录与账号

使用平台交付的 HTTPS 地址登录。普通客户账号在右上角菜单修改密码，新密码至少 12 位；修改成功后所有网页会话失效，重新登录即可。平台预置账号由运维轮换密码。登录失败过多时，按页面提示稍后重试。

客户工作台包含概览、开发机、训练任务、在线服务、存储卷、镜像仓库、资源与队列、用量。账号绑定固定租户；API 同样检查权限。平台管理页面只对管理员开放。

遇到服务故障时保留页面中的错误信息。创建请求超时后，先刷新列表确认是否已经创建，再决定是否重试。

## 创建开发机与 SSH

在「开发机」填写名称、镜像、CPU/GPU 规格和数据卷；需要 SSH 时，在创建时填入工作负载公钥，例如 `~/.ssh/workload_ed25519.pub` 的完整一行。**没有填写公钥的开发机不会运行 SSH 服务**，需要重新创建才能开启。

名称只接受小写字母、数字和连字符，具体长度以表单报错为准。整机预留客户的 GPU 工作负载只调度到该租户的预留节点；共享池客户按已开通的队列和配额调度。点击列表中的机器名称，可以查看实例状态、日志、事件。Pending 的原因应以事件为准。

客户通过内置 SSH 堡垒入口接入，不需要 kubeconfig 或平台管理员权限。平台交付：

- 堡垒域名和端口，默认 TCP 2222。
- 已登记的组织入口公钥，以及开发机使用的工作负载公钥。
- 经过可信渠道核验的堡垒、开发机主机公钥。
- 独立客户端 `alphaapi-access.py`（[源码](../../services/ssh-bastion/client.py)）。

按 [SSH 接入说明](../../runbooks/tenant-access.md#客户连接开发机和传文件) 配置 `~/.ssh/config` 后：

```bash
ssh alphaapi-box
scp model.bin alphaapi-box:/data/
rsync -av ./dataset/ alphaapi-box:/data/dataset/
```

控制台显示的 `.svc` 端点是集群内地址，应使用交付的堡垒连接配置。不要关闭主机身份校验；开发机删除重建后，其主机公钥会变化，需要平台重新核验交付。堡垒本身的主机密钥持久保存。

`/home/dev` 和 `/tmp` 是临时空间；根文件系统只读。重要数据写入创建时申请的 `/data` 数据卷。删除开发机会删除临时空间，**默认保留数据卷并继续计入配额**；不再需要时在「存储卷」单独删除。

已启用 SSH 的机器可以在列表中「替换公钥」。新钥匙通常在 kubelet 配置同步后生效；此操作不会主动断开已经建立的 SSH 会话。紧急撤销请联系平台支持同时处理堡垒入口密钥和现有连接。

## 训练任务与在线服务

训练任务填写镜像、入口脚本、副本数和 GPU 规格。队列采用 gang 调度；整组资源满足条件后才启动。点击任务行查看实例、日志和调度事件。删除前请将 checkpoint 保存到持久卷。

在线服务脚本在容器的 **8080** 端口监听。创建后的 `<name>.<namespace>.svc:80` 端点可从本租户开发机访问。客户本机可以通过堡垒建立私有 HTTP 隧道：

```bash
python3 ~/bin/alphaapi-access.py service model \
  --host ssh.example.com --key ~/.ssh/access_ed25519 \
  --known-hosts ~/.ssh/alphaapi_known_hosts --local-port 8080
curl --fail http://127.0.0.1:8080/
```

替换示例域名、服务名和本地路径。该通道供持有组织密钥的客户使用；当前没有匿名公网推理入口或自动扩缩容承诺。

## 存储与用量

- `arise-shared`：删除卷后清理底层数据。
- `arise-longterm`：删除卷后保留底层数据，需运维确认后清理。Retain 不是备份。

当前存储是节点本地卷，第一次挂载前可能显示 Pending；卷绑定节点后不能自动跨节点访问。控制台的申请容量和配额并不代表底层磁盘已经实施逐卷写入硬限制。重要数据应有独立备份，具体存储限制由开通说明约定。

「用量」显示 GPU 小时、当前 GPU 占用、存储 GiB 小时和分配区间。分配期间包括初始化、镜像拉取及容器重启；未分配 GPU 的排队任务不计 GPU 分配时长。价格、整机预留抵扣及账期按合同和账单执行，网页不是在线支付入口。用量服务不可用或数据过期时应报错，不能把缺失数据当成零费用。

## 安全限制与支持

工作负载不能使用 privileged、hostPath、hostNetwork、平台管理凭据，也不能通过任意节点选择或污点容忍绕过租户隔离。优雅终止最多 300 秒，训练程序应持续保存 checkpoint。

网页账号与 SSH 密钥独立管理。人员离职需要同时撤销网页账号、组织入口密钥、开发机密钥和活动连接。

报障时提供发生时间、对象名、所在页面及错误信息。不要发送密码、私钥或浏览器会话 Cookie。平台可按租户查询操作日志。
