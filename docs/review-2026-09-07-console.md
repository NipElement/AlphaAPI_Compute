# 2026-09-07：控制台视觉与交互重做

此前的浏览器功能验收没有解决控制台的信息层级、操作路径与视觉质量。这一轮重新实现登录界面与全部 13 个工作台页面，并把新增操作纳入真实浏览器验收。新版已发布到 **kind 实验环境**，预览端口仍是开发机的 `127.0.0.1:8888`。

## 查看新版

保持现有 SSH / VS Code 端口转发连接，在本机打开 <http://127.0.0.1:8888>，使用 **Ctrl / Cmd + Shift + R** 强制刷新。若尚未配置转发，在 VS Code 的 Ports 面板转发远端端口 `8888`，然后打开该面板给出的本地地址。继续使用原有实验账号。

首次访问默认浅色；此前保存的深色偏好会保留，可在右上角切换。中英文切换同步更新页面标题和文档语言。

| 区域 | 用户实际获得的变化 |
|---|---|
| 工作台框架 | 统一侧栏、工作空间、管理员导航与顶部操作；原生 SVG 标识、自托管 Inter 字体、统一卡片和状态样式。支持折叠侧栏、手机抽屉、深色模式和减少动画偏好。 |
| 页面导航 | `Ctrl / Cmd + K` 搜索有权限访问的页面，方向键选择、回车跳转；手机菜单支持 Escape、焦点约束与关闭后恢复焦点。 |
| 概览 | 显示实际资源分配、节点容量、工作负载和配额，提供开发机、任务和在线服务快捷入口。未分配 GPU 不冒充实时利用率或保证可用库存。 |
| 开发机 / 任务 / 服务 / 存储 | 默认看资源列表；搜索、状态筛选、分页和行内操作集中展示。点击创建才打开配置抽屉，显示规格、存储、访问配置及资源总量摘要。 |
| 创建流程 | 使用真实规格和运行环境目录；区分 CPU、GPU 与自定义规格；多副本摘要显示总资源。名称校验定位到输入框，接口错误显示在提交按钮旁，失败保留完整草稿。 |
| 资源详情 | 实例配置、节点、事件与日志集中展示。多副本任务可选择实例查看各自日志，支持复制。删除前说明存储保留后果，失败保留对话框。 |
| 连接开发机 / 私有服务 | 分步展示入口、公钥及命令；可下载与仓库一致的独立堡垒客户端。生成命令使用严格主机身份校验；入口主机名、端口未填写正确时不生成误导性命令。私有服务提供本地隧道访问方式。 |
| 运行环境 | 用环境卡片选择实际镜像别名，一键带配置进入创建；名称改为“运行环境”，符合当前功能范围。 |
| 配额与用量 | CPU、GPU、内存和存储使用明确单位，显示已用、剩余和进度。用量支持筛选及对应 CSV 导出；时间采用浏览器时区，未加入虚构单价或余额。 |
| 机群 | 节点卡片展示归属、健康、容量和分配；归属操作在抽屉内展示现有检查门与审批人要求。 |
| 监控 | 1 / 3 / 24 小时时间范围、真实指标请求、可用键盘和鼠标查看的趋势图、节点容量条。空数据、异常和断点有明确处理。 |
| 告警 / 审计 / 用户 | 统一搜索、筛选、时间展示、空状态与错误状态；账号创建校验和删除确认保留后端权限约束。 |

统一组件位于 `web/src/components/`；四类资源页面共用 `ResourceWorkspace.vue`，避免同一操作在不同页面出现不同错误处理。异步加载忽略过时响应，资源列表在页面可见时定期更新；切换租户仍销毁旧表单和详情。

同时修复了实际浏览器中发现的组件问题：表单提交事件用法、Arco 校验提示、输入控件标签、选择器宽度、无效图标、下载参数顺序、多副本日志选择。数字输入使用具名的加减按钮。图标改为显式注册，入口 JavaScript 从本轮初始构建约 391 KB 降至约 96 KB；这是单个入口文件的未压缩大小，不是整个应用体积或加载耗时。

## 结论的边界

这轮验证的是重新设计后的控制台和对应操作链。它不是全量像素差异测试、完整 WCAG 审计、Firefox / WebKit 或手机真机验收，也没有重新执行上一轮所有后端及长稳测试。机群归属检查覆盖表单约束与检查结果展示，未为视觉验收实际切换节点归属。

SSH 页面可生成并下载真实客户端和命令，但上线入口仍需要实际主机名、客户公钥、主机信任材料与部署验收。kind 的模拟 GPU 不能验证真实 CUDA / NCCL / RDMA。此前工程审查记录的存储硬限制、离机恢复与生产入口条件仍见 [前后端复查记录](review-2026-09-06-frontend.md)，没有因视觉重做自动消失。
