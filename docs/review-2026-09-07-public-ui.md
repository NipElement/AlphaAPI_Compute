# 2026-09-07：控制台可读性、主题与操作质量整改

用户实测反馈了字号过小、主题切换多一步、深浅色组件不一致，以及监控时间范围被限制在 24 小时。本轮重新统一基础样式和控件行为，并把主题、弹窗、分页和异常状态加入独立的质量检查。新版预览仍通过开发机 `127.0.0.1:8888` 提供；保持原有端口转发，在浏览器强制刷新即可查看。

## 具体变化

| 问题 | 当前实现 |
|---|---|
| 大量页面写死 8–12px 字号 | 收敛为共享 rem 字号：正文与输入 16px、常规说明 14px、紧凑辅助标签 13px；导航、按钮、表单、表格和图表同步调整尺寸。 |
| 深浅色用下拉菜单切换 | 顶部与登录页都提供直接切换按钮，显示下一种模式的图标和提示。保留已选模式，旧版自动主题偏好在首次加载时解析为明确的浅色或深色。 |
| 页面和组件库主题各自定义颜色 | 页面、Arco body 变量、弹窗、抽屉、菜单、代码块、标签和状态统一引用语义颜色。浏览器原生输入跟随 color-scheme；切换瞬间暂停悬停过渡，避免新文字颜色与旧背景混合；修正浅色危险操作、深色单选按钮、账号菜单、节点归属标签及选中标签页的对比度。六种归属标签在两种主题下均实测超过 5:1。 |
| 切换尺寸时出现暂时错位 | 去掉侧栏宽度和内容边距的独立动画。平板采用抽屉导航，手机顶栏的常用操作保持同一行，管理员的工作空间选择独占第二行，按钮点击区域至少 44px；长用户名截断并提供完整提示，菜单与表格各自滚动。 |
| 监控只能选 1/3/24 小时 | 提供 1/6/24 小时及 3/7/14/30 天，支持最多 90 天的自定义起止时间；校验空值、顺序、未来时间与跨度。 |
| 长时间范围只有小时刻度，缺失历史被压满整张图 | 图表按实际容器宽度布局，长范围包含日期，保留完整查询时间轴；缺失采样断开，只有部分历史时明确提示。键盘与鼠标都可查看样本时间和值。 |
| 监控刷新与查询状态不明确 | 可暂停/恢复自动刷新，保留手动刷新；固定历史区间不自动移动。快速换范围和离开页面会取消旧请求。请求密度限制为每条序列约 600 次评估，并支持指标 CSV 导出。 |
| 分页控件长列表结构有误 | 新增共享 DataTable / Pagination，使用具名按钮、当前页状态、页大小选择与记录范围；筛选后校正页码，表格数据与页面操作保持对应。 |
| 配额进度条没有可访问名称 | 新增共享 QuotaMeter，提供资源名、百分比与具体已用/总量描述。 |
| 自定义 CPU 草稿重新打开被替换 | 恢复创建抽屉时识别自定义规格，保留核心数、内存和选中项；创建期间禁止关闭，点击遮罩不丢失正在编辑的面板。 |
| 概览 CPU / 内存分子分母范围不同 | 两者均按 GPU 节点汇总，并明确标注统计范围；不再把基础设施容量加入只有 GPU 节点用量的分母。 |
| 部分选择器、长选项列表不便键盘使用 | 补齐账号/归属选择器名称，让实际滚动容器可被 Tab 聚焦；保留选择器的方向键操作。 |
| 浏览器拒绝 localStorage 就无法加载 | 偏好读取和保存失败时继续使用内存状态，登录、语言与主题仍可用。 |

主要实现入口：`web/src/styles/global.css`（设计变量和页面基础样式）、`web/src/styles/controls.css`（组件统一规则）、`web/src/stores/ui.ts`、`web/src/components/DataTable.vue`、`Pagination.vue`、`QuotaMeter.vue` 和 `web/src/views/MonitoringView.vue`。

## 与上线有关的边界

监控的**可查询区间不等于数据保留承诺**。当前配置是 lab 保留 3 天、dgx 保留 15 天；选更长范围会保留空白和缺失提示，不伪造数据。延长保留周期还需要按真实采集量规划存储。

自动检查发现的问题必须修复，但规则通过仍不能代替人工视觉判断、完整可访问性审计或真实设备验收。axe 的 `incomplete` 项也随报告保留。本轮不把 Chromium 结果表述为 Firefox/Safari 全覆盖，不把模拟 GPU 表述为硬件验收。

这轮交付更新实验预览并构建本地前端镜像，没有发布生产服务。生产存储硬限制、异机备份恢复、公网域名/证书/SSH 信任材料、持续负载和真实 GPU 验收仍按 [既有生产复查记录](review-2026-09-06-frontend.md) 执行。
